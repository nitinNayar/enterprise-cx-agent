# Bookly Branding Assets - README

## ⚠️ Temporary Placeholder Images

The current `Bookly_Light.png` and `Bookly_dark.png` files are **temporary placeholders** copied from the previous TrueCart branding.

## Action Required

**Custom Bookly logo files need to be created** to properly represent the bookshop brand.

### What's Needed:
1. **Bookly_Light.png** - Logo for light theme
   - Dimensions: 300x300px minimum
   - Format: PNG with transparent background (or SVG)
   - Style: Book-themed, modern, professional

2. **Bookly_dark.png** - Logo for dark theme (optional)
   - Same specifications as light version
   - Optimized for dark backgrounds

### Design Specifications

See `/docs/BOOKLY_BRANDING_SPEC.md` for complete branding guidelines including:
- Color palette recommendations
- Logo concepts
- Typography specifications
- Icon style guide

### How to Create New Logos

**Option 1: AI Image Generators**
- Use DALL-E, Midjourney, or Stable Diffusion
- Prompt: "Modern minimalist logo for Bookly bookshop, open book icon, blue and brown colors, clean lines, transparent background"

**Option 2: Design Tools**
- Figma (free, web-based)
- Canva (free tier available)
- Adobe Illustrator (professional)
- Inkscape (free, open-source)

**Option 3: Hire a Designer**
- Fiverr, Upwork, or 99designs
- Budget: $10-100 depending on requirements

### Replacing Placeholder Images

Once new logos are created:

1. Save new files as:
   - `Bookly_Light.png`
   - `Bookly_dark.png`

2. Place in this `/public/` directory

3. The application will automatically use new logos (no code changes needed)

4. Delete this README_BRANDING.md file
